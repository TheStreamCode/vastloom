# Support

Vastloom is experimental alpha software, provided without warranty.

- Use GitHub Issues for reproducible defects and focused feature proposals.
- Use GitHub Discussions for setup questions, hardware observations and research ideas.
- Use the private contact in [SECURITY.md](SECURITY.md) for vulnerabilities.

Before reporting a bug, run `vastloom version`, `vastloom doctor --json`, and the smallest
relevant self-test. Include the commit, operating system, compiler, CPU, GPU, RAM, exact
model revision, command and complete non-sensitive error output. Do not upload model weights,
API keys, personal prompts or proprietary data.

The current release does not promise DeepSeek V4 Flash support, CUDA inference, production
SLAs or a local HTTP API. Community support is best effort.
