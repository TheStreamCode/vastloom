# Vastloom 0.5.0-alpha.1 — concluded research record

Vastloom is concluded research software, not a product, and it does not claim competitive
throughput. This tag freezes the working record.

## What is in this record

- **DeepSeek V4 Flash 0731 reduced-payload execution**: 780,087,788 B of hash-verified range
  slices instead of the 90.86 GB checkpoint; one real layer and a deterministic three-layer
  hash-routed chain.
- **Independent NumPy oracles**: layer-0 logits within 9.54e-07, chain logits within 1.91e-06,
  and a five-token prefill that opens the layer-2 4:1 compressed window (logits within 1.91e-06,
  hidden within 5.96e-08).
- **Device expert residency with bounded CPU fallback**: bit-identical logits to the CPU reference
  under a forced VRAM cap.
- **Serve safety on the dense SmolLM2 path**: JSON-object constrained decoding, fail-closed
  control-token rejection and UTF-8-safe SSE streaming.
- **65 dated validation reports**, green CI/CodeQL/Docs, and a documented resume backlog.
