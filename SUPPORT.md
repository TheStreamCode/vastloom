# Support

Vastloom is concluded research software, provided without warranty. Active
development ended in October 2026; the repository is preserved as a working
public record.

- Use GitHub Issues for reproducible defects in the preserved release.
- Use GitHub Discussions for setup questions, hardware observations and
  research ideas.
- Use the private contact in [SECURITY.md](SECURITY.md) for vulnerabilities.

Before reporting a bug, run `vastloom version`, `vastloom doctor --json`, and the smallest
relevant self-test. Include the commit, operating system, compiler, CPU, GPU, RAM, exact
model revision, command and complete non-sensitive error output. Do not upload model weights,
API keys, personal prompts or proprietary data.

The preserved release includes the loopback-only OpenAI-compatible endpoints
documented in the README. It does not promise full DeepSeek V4 Flash support,
complete CUDA inference, production SLAs, new features, or response timelines.
Community support is best effort.
